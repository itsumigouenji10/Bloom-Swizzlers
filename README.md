## 🧠 Abstract

**Bloom Swizzlers** is a novel construction designed to expand the expressiveness of Private Information Retrieval (PIR) protocols. Traditional PIR schemes are typically limited to basic keyword queries and simple lookups. This project introduces **Bloom Swizzlers** as an indirection layer, enabling **expressive, single-round queries**—including conjunctive, disjunctive, and even aggregate operations—while preserving PIR’s privacy guarantees.

---

## 🎯 Key Contributions

- Introduced **Bloom Swizzlers**, a new construction layer using Bloom filters and matrix-based transformations
- Enabled support for **AND / OR / AGGREGATE** keyword queries in PIR systems
- Developed a **Python-based proof-of-concept** implementing the Bloom Swizzler design
- Performed theoretical and experimental evaluations on system scalability and linear independence
- Demonstrated compatibility with both XOR-PIR and homomorphic encryption-based schemes (BFV)
